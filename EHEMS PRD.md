## PART A — FOUNDATION

## 1. Executive Summary

EHEMS is a Nigerian healthcare entrepreneurship platform that trains, mentors, and certifies healthcare workers to build sustainable businesses. The platform combines six membership tiers, a certificate catalogue of 30+ professional credentials, structured mentorship programmes, physical and digital product sales, events, and community access delivered through external WhatsApp/Telegram channels.

**Phase 1** delivers a responsive web application with manual payment verification, a member dashboard, an admin/staff control panel, tier management with upgrade pricing, attendance recording, manual completion marking, and certificate issuance. The platform is designed as an extensible membership ecosystem — not a one-off website — with architecture prepared for QR attendance, automated scoring, internship management, and payment gateway integration in later phases.

**Confirmed commercial context:** One-time payments only. No recurring tier subscriptions. Target launch: 3 months from commencement of development. Budget range: ₦2,500,000 – ₦3,500,000.

**Market intelligence** (Section 2) examines the Nigerian healthcare entrepreneurship training landscape, identifies key competitors, and provides a SWOT analysis positioning EHEMS against established and emerging players.

## 2. Market Intelligence

### 2.1 Market Context

Nigeria's healthcare professional development market is experiencing significant growth driven by several factors:

- **Workforce gaps:** Healthcare students are trained almost exclusively for clinical careers with minimal exposure to product development, venture building, or innovation workflows.
- **Entrepreneurship demand:** Over 1,300 medical science students have accessed entrepreneurship training and mentorship through university-led programmes, demonstrating strong appetite.
- **Digital learning adoption:** Low-bandwidth, mobile-optimised learning platforms are gaining traction, with platforms like cIDSR delivering self-paced material accessible in low-bandwidth environments.
- **Regulatory push:** The Medical and Dental Council of Nigeria (MDCN) operates a CPD training platform for registered practitioners, signalling institutional acceptance of digital professional development.

The market is fragmented. No single platform combines mentorship, certification, community, and business education for healthcare entrepreneurs in a tiered, credential-bearing format.

### 2.5 Strategic Implications for Phase 1

1. **Lead with the free tier.** The O'Free level is EHEMS's strongest competitive differentiator. It should be prominently featured and easy to join.
2. **Emphasise the certificate catalogue.** 30+ certificates is a tangible value proposition that competitors cannot match at this price point.
3. **Position the mentor pathway as career advancement.** Being a mentee first, then qualifying as a mentor, creates aspiration and loyalty.
4. **Build for mobile-first.** The target audience accesses content primarily via smartphones.
5. **Prepare for NDPA compliance now.** Healthcare professionals' data is sensitive; registration with NDPC may be required if >200 members in 6 months.
6. **Plan for accreditation conversations.** MDCN CPD accreditation would significantly strengthen the certificate value proposition.

## 8. Core User Journeys

### 8.1 Visitor → Free Member

```
Visitor lands on site
→ explores services (Group Mentorship, Personal Mentorship, Coaching)
→ clicks "Join Free" or "Learn More"
→ directed to WhatsApp Probation Room
→ signs up on site (name, email, phone, profession)
→ receives orientation
→ downloads brochure + FAQ
→ becomes O'Free member
→ receives dashboard access
→ sees upgrade prompts for paid tiers
```

### 8.2 Free Member → Paid Member

```
O'Free member explores paid tiers
→ selects tier (e.g., Basic III)
→ clicks "Subscribe"
→ sees payment instructions (bank transfer/mobile money)
→ makes payment offline
→ uploads proof of payment
→ submission enters admin verification queue
→ admin reviews and verifies
→ tier activated
→ member dashboard updates
→ community link revealed
→ email confirmation sent
→ receipt issued
```

### 8.3 Paid Member → Completed → Certificate

```
Member participates in programme
→ attends sessions (manually marked by admin in Phase 1)
→ completes assignments/tests (admin checklist)
→ receives feedback from mentor
→ admin reviews: attendance ≥60%, assignments complete, performance satisfactory
→ admin marks member as "Completed"
→ system issues certificates mapped to tier
→ member downloads certificates from dashboard
→ mentor eligibility flag set (if criteria met)
```

### 8.4 Admin Payment Verification

```
Payment submitted by member
→ appears in admin verification queue
→ admin views payment details and proof
→ approves or rejects
→ if approved: member tier activated, community link unlocked
→ if rejected: member notified with reason, resubmission allowed
→ audit log records action
```

## 12. Programme, Learning & Mentorship System

### 12.1 Programme Structure

Each programme contains:

- **Programme metadata:** Title, description, duration, attendance threshold (default 60%)
- **Sessions:** Dated sessions with location type (physical/virtual/hybrid)
- **Materials:** Tier-gated resources (PDFs, videos, audio, links)
- **Assignments:** Tracked via admin checklist (Phase 1)
- **Mentorship:** Linked to tier duration

### 12.2 Mentorship Model

Mentorship spans across packages and programmes. Durations: Basic 1 month, Basic III 1 month, Advanced IV 2 months, Advanced V 3 months, Higher Advanced VIII 6 months. A member can have multiple enrolments over time. Model as User → Enrolments → Programmes/Tiers → Entitlements.

### 12.3 Attendance (Phase 1)

- Admin manually marks attendance per session
- System computes attendance percentage per member per programme
- 60% threshold displayed prominently
- Attendance feeds into completion eligibility

- Attendance recorded per session per member

- Certificate catalogue mapped to tiers
